# Morpho
An all-in-1 single Python file converter. Can convert:

- Slides (pptx, ppt, odp, key) to PDF, PPTX, ODP, or one PNG/JPEG per slide.
- Documents (docx, doc, odt, rtf, txt, html, md, pages) to PDF, DOCX, ODT, RTF, TXT, HTML, Markdown, per-page images, or EPUB/MOBI/AZW3.
- Spreadsheets (xlsx, xls, ods, csv, numbers) to PDF, XLSX, ODS, CSV, HTML.
- PDF to smaller PDF, per-page PNG/JPEG/TIFF, TXT, or DOCX/ODT with a layout warning.
- Video, audio, images, SVG, HEIC as before, plus SVG and image to PDF.
- Subtitles (srt, vtt, ass) and archives (zip, 7z, tar.gz, tar.xz, tar.zst, RAR read-only).
